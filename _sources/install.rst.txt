.. _install:

Installation
============

Prerequisites
-------------

+ Java 1.8 or higher

  * Java Runtime (JRE) or Java Development Kit (JDK).

+ Python 3.11 or higher

  * https://www.python.org/
  * Java 17 is a primary test environment.

+ pip

  * https://pypi.org/project/pip/

Install
-------

  .. parsed-literal::

    python -m pip install --upgrade jni
